# STUDY BURST TCG — RPG1

勉強をしてパックを開け、40枚デッキを組んでCPUと対戦するオリジナルTCG。デュエマ風のシールド・文明・マナ・進化・シールド逆転の遊びに着想を得ています。既存カード名やアートは使用していません。

## ファイル
`index.html`, `style.css`, `cards.js`, `script.js`, `data/questions.json`。GitHub Pagesのルートに配置するだけで動作します。外部ライブラリ不要。カードイラストはCanvas生成の低解像度ドット絵。後日 assets/cards/*.webp に差し替え可能。

## 操作
- 最初に3つのスターターから1つを選ぶ。40枚デッキとカード40枚が提供される。
- STUDYで5問正解するごとに1パック。間違えた問題は復習に登録。ローカルCSV/JSONも追加可能。
- PACKで5枚入りパックを開封してカード収集。
- DECKで所持カードから40枚のデッキを編集。同名4枚まで。
- DUELでCPU戦。手札カードをタップし、マナに置くかプレイ。自身のクリーチャーをタップして攻撃対象を選ぶ。1ターンのマナ追加は1枚。
- シールドが割れると手札へ移動。バースト持ち呪文は無償発動可能。シールドが無い状態に直接攻撃を通すと勝ち。山札が引けなければ負け。
- CODEXで未所持・カード効果・所持枚数を確認、重複カードを素材に変換してクラフト。

## 現版の制約
正式なデュエル・マスターズの完全再現ではありません。1文明支払い、簡易自動ブロック、簡易CPU、独自のカード能力・効果処理を採用しています。同期オンラインPvP、詳細なチェーン解決、全能力種別の実装は今後のフェーズです。

## 保存
`localStorage` の `studyBurstTCG.v1` を使用。以前のSTUDY FORGEセーブキーは触りません。バトル中の一時状態は保存しません。GitHubの旧版ゲームは `backup-monster-game-20261012` ブランチにバックアップします。
