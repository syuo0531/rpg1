# STUDY SURVIVOR RPG1 — v4 (Type Matchups & Switching)

GitHub Pages で動作する HTML/CSS/JS ブラウザゲームです。既存の学習・ガチャ・151匹図鑑・セーブシステムを維持しています。

## v4 の新機能

- 3匹の手持ちから **戦闘に出すのは1匹だけ**。控えは攻撃しません。
- 戦闘画面下の手持ちカードを押して随時交代。PC は数字キー 1 / 2 / 3。交代待ち時間2.5秒、交代直後0.75秒の被弾保護。
- 出撃中のHPは **ポケモン別に保存**。ひんしになると生存中の控えへ自動交代。全滅でゲームオーバー。
- タイプ相性により攻撃・被ダメージを変化。**有利1.6倍、不利0.65倍、通常1倍**。相性結果は敵付近の表示と数字で確認できます。
- 育成Lv・ポケモンの基礎HP/攻撃・進化段階で強さに差があります。進化時はHP割合を維持します。

## 現在のタイプについて

初期151匹の既存データは、草・炎・水・雷・念・闘・毒（内部名 dark）・竜・無の **9種類に簡略化された単一タイプ** です。公式の18タイプ・複合タイプを完全に再現したものではありません。マッチアップは `script.js` の `TYPE_CHART` で拡張できます。

## 操作

- PC: WASDまたは矢印キーで移動、数字キー1〜3で交代
- スマホ/iPad: フィールドをドラッグして移動、画面下の手持ちポケモンをタップして交代
- 勉強: 5問正解ごとにガチャ券1枚、ガチャ1回でポケモン1匹

## 保存

保存キーは `studySurvivor.v1` のままです。既存の所持ポケモン、問題履歴、育成Lv、ステージ、ガチャ券を継承します。戦闘中の各ポケモンHPはランごとの一時データで、次の出撃時に回復します。
