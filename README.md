# STUDY BURST TCG — RPG1 v1.1 (2026-10-12)

学習問題に正解してブースターパックを開けるオリジナルブラウザTCG。40枚デッキ、5シールド、5文明、CPU戦、カードクラフト、CSV/JSON学習問題インポート、localStorageセーブ対応。既存カードゲームの機構に着想を得ていますが、カード名・イラスト・世界観はオリジナルです。

## v1.1 変更点

- **レア保証なし**。1パック5枚、各カードは次の確率で独立抽選：N 72%、U 20%、R 6%、SR 1.6%、LEGEND 0.35%、SECRET 0.05%。すべてNのパックも出ます。
- **累積救済**。R以上が9パック続けて出なければ10パック目にR以上、SR以上が29パック続けて出なければ30パック目にSR以上、LEGEND以上が99パック続けて出なければ100パック目にLEGEND以上を1枚保証。各救済カウンターは対象ランク以上を引くと0に戻ります。
- **SECRET 5種追加**。既存LEGENDの同能力・別デザインのホログラム仕様。合計75種。
- **カードデザイン刷新**。5文明別の金属枠、アート領域の拡大、コスト六角紋章、能力テキスト、レア度別ホロ、オリジナルの新規生成ピクセルアート（`cardart.js`）。画像URLや外部ライブラリ不要。
- **収集難度調整**。クラフト費用を再調整。CPU戦は1勝でSHARDS +5、10勝で1パック。敗北は+1。パック獲得は学習が中心。
- v1セーブキー `studyBurstTCG.v1` を継続使用して所持カード・デッキ・問題履歴を維持。新しい救済カウンターのみ初期値で追加。

## 遊び方

1. 3種類のスターターデッキから一つを選ぶ。40枚と最初のパックを取得。
2. STUDYで5問正解すると1パック獲得。問題CSV/JSONの追加可能。
3. PACKで5枚開封。まったくレアがないパックもあります。累積救済と排出率はPACK画面で確認。
4. DECKで所持カードから40枚を編成（同名4枚まで）。
5. DUELでCPUと対戦。マナを置き、クリーチャーを出し、シールドを破り、最後に直接攻撃して勝利。
6. CARDSで収集図鑑、クラフト、重複カードの分解を利用。

## 構成

`index.html`, `style.css`, `cards.js`, `cardart.js`, `script.js`, `data/questions.json`。GitHub Pagesでそのまま動作。画像はブラウザのCanvasで生成するためネットワーク画像依存なし。

## 制限事項

正式なデュエル・マスターズのルールそのものではなく、オリジナルの簡易ルールです。CPUの思考、能力対象選択とブロック判定は簡略化されています。オンライン対戦は未実装。バトル途中のセーブは行いません。既存のモンスター育成RPGデータは別のセーブキーなので削除しません。
