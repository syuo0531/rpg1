GitHub Pages compatible. Save key `studySurvivor.v1` unchanged.

- Eight dungeons (5 new), with separate bosses and increasing HP.
- Eight Kanto gym leaders, sequential badges and dedicated gym battles. Leader teams are consecutive boss phases. The eighth Viridian gym with Giovanni is the most challenging and has four bosses.
- Gacha 1/512 shiny and successful post-battle capture 1/256 shiny. Shinies are stored separately from base species and can be selected via the Pokémon details screen.
